# Sales-Dashboard-Power-BI
Interactive Sales Dashboard analyzing orders, customers, sales performance, products, categories, and yearly trends.

## Project Overview

This project presents an interactive **Sales Dashboard** designed to analyze sales performance, customer activity, product performance, and sales trends across different years and product categories.

The dashboard combines key performance indicators with interactive visualizations and filters to provide a comprehensive view of sales performance.

## Project Objectives

- Analyze overall sales performance
- Track total orders and customers
- Identify top-performing products
- Analyze sales by product category
- Examine sales trends across years and quarters
- Compare sales across different countries
- Enable interactive analysis using dashboard filters

## Dashboard Features

### Key Performance Indicators

The dashboard displays:

- Number of Orders
- Number of Customers
- Total Sales

### Product Analysis

A product-level sales analysis identifies products generating the highest sales and allows comparison across the product portfolio.

### Product Category Analysis

Sales are segmented across categories including:

- Laptop
- Smartphone
- Tablet
- Smart Home
- Accessory

### Time Analysis

The dashboard visualizes sales trends by:

- Year
- Quarter

This helps identify changes and fluctuations in sales performance over time.

### Geographic Analysis

Sales can be filtered by country, including:

- China
- Germany
- India
- United States

### Interactive Filters

Users can filter the dashboard by:

- Product Category
- Year
- Country

These filters allow users to drill down into specific segments of the sales data.
